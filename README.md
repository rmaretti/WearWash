# Wear & Wash

Track what you wear. Know when to wash.

Wear & Wash is an Android-first wardrobe care and laundry readiness app. The MVP is planned as a native Android app built with Kotlin, Jetpack Compose, and Room.

## Current Skeleton

This repository currently contains:

- Android Gradle project structure
- Jetpack Compose starter screen
- Room entity skeletons for items, usage, wash events, laundry basket, and future events
- Initial localized string resources for English, Spanish, and Brazilian Portuguese
- Domain models for item status and washing criteria
- Washing readiness evaluation logic
